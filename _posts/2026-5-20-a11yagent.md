<strong style="font-size: 1.2em;">Did you know that VS Code has over <span class="statistic">77</span> settings just to make the IDE more accessible?</strong> 
<br>
VS Code has 100s of settings, many of these designed specifically for blind and low-vision (BLV) developers. Around <span class="statistic">3</span> accessibility-related features are introduced or changed every month, with some months having as many as <span class="statistic">11</span> changes (based on analysis of Release notes from January 2021- December 2025).

Discoverability is a known challenge for BLV developers. Prior studies have found limited use of IDE features by BLV develoeprs ([Mealin et al., 2012](https://ieeexplore.ieee.org/stamp/stamp.jsp?tp=&arnumber=6344485))and have indicated that features visible to sighted developers often remain hidden to BLV developers ([Albusays et al., 2017](https://dl.acm.org/doi/epdf/10.1145/3132525.3132550); [Baker et al., 2015](https://dl.acm.org/doi/epdf/10.1145/2702123.2702589); [Potluri et al., 2018](https://dl.acm.org/doi/epdf/10.1145/3173574.3174192)).

Given the sheer number of settings in VS Code and the pace at which they are introduced and changed, they risk not being discovered and used in practice.

## Introducing a11yagent

`a11yagent` is a VS Code extension that helps BLV developers discover features and troubleshoot accessibility-related issues within the IDE. It provides an interactive chat participant where users can ask questions and find and track updates related to accessibility issues they are facing in VS Code.

a11yagent uses the same language models that GitHub Copilot uses, but grounds its answers in accessibility-specific data extracted from various sources including the official VS Code documentation, release notes, settings, default keybindings, signals/ announcements, GitHub issues, and telemetry logs so that the generated answers are more relevant for BLV developers.

You can install and start using a11yagent from the Visual Studio Code marketplace [Visual Studio Code marketplace](https://marketplace.visualstudio.com/items?itemName=IDEA.a11yagent)!


## Why a11yagent?

### 1. Users have a lot of questions about VS Code features

An analysis of posts about VS Code on program-l - the popular discussion forum used by BLV developers - underscores the prevalence of discoverability-related issues. A mixed-methods analysis of these posts using data from 2021-2025 shows that <span class="statistic">31.2%</span> of all queries about VS Code are users seeking help with finding features to complete a task. Queries are higher for some features - they are highest for features related to the editor (<span class="statistic">16.7%</span>), followed by keyboard workflows (<span class="statistic">13.8%</span>), terminal (<span class="statistic">12.3%</span>), and sound cues (<span class="statistic">11.6%</span>).

### 2. The built-in chat agent performs poorly when asked these questions

An IDE-native chat agent like GitHub Copilot could, in theory, help answer these user queries and assist developers in discovering and using various features of VS Code. However, in practice, Copilot frequently provides responses that are mouse-based, contain hallucinated settings, or exclude relevant ones.

## Features

### Accessibility chat participant
Users can ask questions about using VS Code or describe their workflows/goals by invoking the agent with `@a11yagent`. a11yagent will answer with relevant features and settings that can assist in these workflows and provide screen-reader-optimized steps to access and use these features. Users can also ask follow-up questions and continue a conversation with the agent, if they wish to do so.

### Accessibility issue search
If a user's query describes issues in using specific features, a11yagent uses the GitHub MCP server to return a list of relevant GitHub issues, possible workarounds mentioned in the comments, and timelines/plans for addressing the issue, if present.

Users can choose to track any of these issues to receive updates when they are being worked on/resolved. They can also log their description so that a11yagent can notify them if relevant issues are found in the future.

<strong>Why this feature?</strong>  19.9% of all queries about VS Code on program-l are users seeking help in troubleshooting issues they face in using specific features/settings. Many of these are already documented on GitHub and actively being worked on by the VS Code team.
